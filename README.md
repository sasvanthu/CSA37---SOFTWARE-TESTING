## Running the code
- **JUnit / Selenium folders** are standalone Maven projects (Java 17): `mvn test` or `mvn compile exec:java`.
- **Manual folders** hold the test documents (README + CSV tables).
- **JMeter folders** hold the test plan configuration to build in JMeter.
